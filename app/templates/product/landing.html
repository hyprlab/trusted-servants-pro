Run it on your own server.

It is one Flask app with a SQLite database. The installer sets up a production server with HTTPS, automatic updates and disk cleanup. Docker Compose runs it on any machine with Docker.

Read the full documentation

Option A · production + HTTPS

One-command installer

For a public server. It installs Docker, writes a Compose file, generates a secret key, and sets up Caddy to get a Let's Encrypt certificate. After that it updates the app and clears out old files on its own.

  1. Provision a server

    Start a fresh Ubuntu 24.04 LTS server with any provider (DigitalOcean, Hetzner, Lightsail) or on your own hardware. 1 vCPU and 1 GB of RAM is enough for most fellowships. Sign in over SSH as root or a user with sudo.

    $ ssh root@your-server-ip
  2. Point your domain at it

    For a real certificate, add a DNS A record that points your hostname at the server's IP address. On Cloudflare, set it to “DNS only” (gray cloud) while installing so the certificate check can reach the server. Without a domain, the installer uses a self-signed certificate.

    # DNS A record
portal.yourfellowship.org   →   203.0.113.10
  3. Run the installer

    Run the install script from GitHub. If you want to read it first, download it or clone the repository.

    $ curl -fsSL https://raw.githubusercontent.com/\
hyprlab/trusted-servants-pro/main/install.sh | sudo bash
  4. Answer two prompts

    Enter your domain (or press Enter for a self-signed certificate) and an email address for certificate notices. It then downloads the app and starts it, which takes 2 to 5 minutes. To skip the prompts, give the answers as variables.

    # interactive prompts
Domain (blank = self-signed): portal.yourfellowship.org
Contact email: you@yourfellowship.org

# …or fully non-interactive
$ sudo TSP_DOMAIN=portal.yourfellowship.org \
       TSP_ACME_EMAIL=you@yourfellowship.org \
       TSP_ADMIN_PASSWORD='a-strong-password' bash install.sh
  5. Sign in & secure it

    Open the address the installer prints and sign in with the admin password it generated, which is also saved in /opt/tspro/.env. You set up two-factor authentication at first sign-in.

    → https://portal.yourfellowship.org
   username : admin
   password : (printed by the installer)
Option B · any machine

Docker Compose

Runs on a laptop, a home server or any VPS: one container and one SQLite file.

  1. Check Docker is installed

    You need Docker Engine and the Compose plugin. Check that both are installed.

    $ docker --version && docker compose version
  2. Create a compose file

    In an empty folder, create a docker-compose.yml that uses the published image.

    # docker-compose.yml
services:
  tsp:
    image: hyprlab/tspro:latest
    container_name: tspro
    ports:
      - "8090:8000"
    volumes:
      - ./data:/data
    environment:
      - TSP_SECRET_KEY=${TSP_SECRET_KEY:?TSP_SECRET_KEY must be set in .env}
      - TSP_ADMIN_PASSWORD=${TSP_ADMIN_PASSWORD:?TSP_ADMIN_PASSWORD must be set in .env}
    restart: unless-stopped
    # cap logs so they can't fill the disk over time
    logging:
      driver: json-file
      options: { max-size: "10m", max-file: "3" }
  3. Set a secret key and admin password

    The secret key signs session cookies, and the password is for the first admin account. The app won't start without both, so put them in a .env file.

    $ echo "TSP_SECRET_KEY=$(openssl rand -hex 32)" > .env
$ echo "TSP_ADMIN_PASSWORD=$(openssl rand -base64 18)" >> .env
$ cat .env   # note the password
  4. Start it

    This downloads the image and starts the container in the background on port 8090.

    $ docker compose up -d
  5. Open it

    Open the public site or the admin, and sign in as admin with the password from .env. You set up two-factor authentication at first sign-in.

    → http://localhost:8090         # public site
→ http://localhost:8090/tspro   # admin
