{# Reusable "?" help chip. Collapses a field's helper paragraph into a click-to-open tooltip so the form reads as labels + inputs instead of labels + inputs + three lines of prose each. Emits exactly the markup the topbar heading help uses (.heading-help / .help-btn / .help-tooltip), so the shared click / Escape handler in app.js drives it with no extra wiring — the extra .field-help class only carries the smaller inline sizing. chip(label) the bare chip. Drop it after a heading you've already written: a card

, a .post-subhead, a toggle title. hrow(label) a label heading row — the label text with the chip pinned to its right. Needed inside `.form label`, which is a column flex container: without the inline wrapper the chip would drop onto its own line above the input. Both take the tooltip body as a {% call %} block, so help text can carry markup: `label` is only used for the button's accessible name; the visible mark is always the Lucide `info` icon. #} {% macro chip(label='') -%} {{ caller() }} {%- endmacro %} {% macro hrow(label) -%} {{ label }}{{ caller() }} {%- endmacro %}
