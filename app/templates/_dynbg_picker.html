{# Dynamic-background trigger button. Drop-in replacement for any admin form that needs a "pick a dynamic background" affordance. Renders: 1. Five hidden s carrying the current selection — base key, overlay key, and three custom colour slots — so a normal form POST submits everything in one shot. The consumer routes each value through ``app.dynbg.normalize*`` / ``normalize_color`` server-side to clamp tampered values. 2. A button that opens the global dynbg modal (rendered once in base.html). The modal reads the trigger's current values, lets the admin pick a different background / overlay / paint a custom palette, and writes the chosen values back to the hidden inputs on Save. The trigger preview re-uses the same inline thumbnail recipe the modal does, so the button shows what's currently selected without having to crack open the modal.
